# 模式说明与交互笔记（即梦 Seedance 2.0 / Seedancer）

## 模式选择

### 1) 纯文本模式（Text-to-Video）
没有参考素材时使用。提示词必须承载所有视觉引导：风格、色调、角色描述、镜头、时间线节拍。

适用场景：
- 原创角色/生物概念设计
- IP 安全的抽象场景
- 快速概念验证

最佳实践：
- 开头声明比例、时长、帧率和风格
- 角色/生物使用完全原创名称和独特特征
- 所有动作用五维度节拍描述
- 提示词控制在 200 字以内（过长会生成失败）

### 2) 首帧模式（Image-to-Video）
上传单张首帧图片（或首帧+尾帧）加文本提示词。模型从首帧出发生成动画。

适用场景：
- 已有概念图/分镜图需要动画化
- 口播视频（上传角色照片 + 音频）
- 产品展示（上传产品照片）

关键技巧：
- 首帧构图决定最终画面的起点，确保主体位置合理
- 尾帧可选上传，模型会自动生成中间过渡动作
- 首尾帧主体位置和姿态需合理衔接

### 3) 全参考模式（Reference-to-Video）
同时上传图片和视频、音频进行多模态控制。赋予创作者对表演、光影、运镜的调度权。

适用场景：
- 需要精确复刻某段运镜或动作
- 角色一致性要求高的多镜头序列
- 音乐节拍同步
- 复杂多资产场景

### 4) 视频延长模式（Extend）
上传已有视频作为 `@视频1`，写 `延长 @视频1 X 秒`。模型从原视频结尾继续生成。

⚠️ **关键规则**：
- 生成时长选择 = **新增片段的时长**，不是最终总时长
- 提示词中需包含连续性描述（角色从上一段结尾动作直接过渡到新动作）
- 交接帧需稳定姿态、清晰构图

### 5) 视频编辑模式（Edit）
对已有视频的指定片段、角色、动作或剧情进行定向修改。

适用场景：
- 替换视频中某个角色
- 修改特定动作或特效
- 调整场景元素

## @asset 引用模式

始终在提示词正文之前映射素材，减少错误：

```text
素材映射：
- @图片1 = 首帧 / 角色身份锚定
- @图片2 = 环境风格参考
- @视频1 = 运动 + 镜头参考
- @音频1 = 音乐节奏 / 台词音频
```

在 12 个文件限制内，按影响力排序使用：
1. 核心视觉风格（2-3 张图）
2. 角色/主体参考（1-3 张图）
3. 动作/镜头参考（1 段视频）
4. 音频基础（1 段音频）
5. 支持细节（剩余插槽）

## 可充分利用的控制能力

Seedance 2.0 擅长：
- **多镜头叙事**：自动生连贯的多镜头序列，角色/场景/氛围全程一致
- **音画同步**：原生双声道立体声，含背景音乐/环境音效/口型同步（8+ 语言）
- **物理仿真**：高级模式适合运动、碰撞场景（基础/可选）
- **角色一致性**：跨镜头保持面部特征、发型、配饰完全一致
- **运镜复刻**：准确复制推拉变焦、跟踪镜头和机械臂多角度跟拍
- **视频延长**：将片段链式连接超过 15 秒限制
- **视频编辑**：对指定片段/角色/动作/剧情进行定向修改

## 导演交互流程

### 第一次交互（收到剧本/想法后）
向导演确认以下变量：

1. **视觉风格基调**：全局美学倾向
   - 示例选项：高反差纪实 / 复古科幻 / 现代极简 / 水墨国风 / 赛博朋克
   
2. **时长策略**：叙事节奏倾向
   - 动作快切（短镜头组接）vs 长镜头叙事（一镜到底）
   
3. **超自然规律**：特殊能量或物理现象的视觉表现
   - 示例：法术粒子密度 / 能量颜色 / 重力异常表现方式
   
4. **生成模式**：根据用户素材情况选择
   - 纯文本 / 首帧 / 全参考

### 后续交互（输出初版提示词后）
- 导演可针对任一维度要求调整（如"把光影改暗一点"、"节奏再快一些"）
- 根据反馈修改后重新输出

## 对白与音效设计

当提示词包含角色台词或音效时，将其作为视觉方向的**独立层级**：

```text
[时间段]：[视觉动作和镜头]
对白（角色名，情绪）："台词"
音效：[环境/效果描述]
```

最佳实践：
- 每 3-5 秒时间段最多一条对白
- 情绪显式标记：`冰冷`、`绝望`、`欢快`、`耳语`
- 音效单独描述：脚步声、环境嗡鸣、配乐高潮、寂静
- 结尾音频收束：`配乐淡出`、`环境风声`、`寂静`
- 口播视频必须开启口型同步，确保音频清晰无杂音

## 多段工作流（超过 15 秒）

### 路径一：视频延长接力（推荐新手）
1. 开头声明 **总时长** 和 **分段数量**
2. 第一段：正常生成，结束于**干净的交接帧**
3. 第二段及之后：上传上一段作为 `@视频1`，使用 `延长 @视频1 X 秒`
4. 每段末尾包含 **交接帧描述**
5. 向前传递：身份、服装、光照、镜头风格、场景连续性

### 路径二：分段独立生成 + 剪辑拼接（高级，质量更可控）
1. 所有段落共用同一套角色图和场景图
2. 每段独立生成，使用统一的 prompt 模板
3. 最后辑软件中拼接，可添加过渡效果

## 一镜到底/连续镜头技巧

- `@图片1` 作为首帧（主角/开场构图）
- 额外图片作为 **场景路标点** — 镜头经过的地点、角色或道具
- 将提示词写成一条连续摄像机路径，按顺序经过每个路标点
- 明确注明：`无剪辑、单镜头连续拍摄、一镜到底`
- 15 秒配合 3-5 个路标点效果最佳

## 产品展示技巧

- 将产品照片绑定为 `@图片1`，作为身份锚定
- 技巧：**360° 旋转**、**3D 爆炸视图**、**重组卡合**、**英雄光效**
- 指定材质渲染：`玻璃反射`、`金属光泽`、`哑光质感`、`半透明辉光`
- 背景保持干净：影棚渐变、中性表面或情境化生活场景

## 口播视频批量工作流

适合系列内容（如每天一条知识分享）：
1. 建立统一角色档案（多角度照片：正面/侧面/表情特写）
2. 写标准 prompt 模板，每段仅替换动作描述和音频
3. 使用视频延长功能接力生成，或使用分段独立生成 + 统一参考
4. 每段控制在 10-13 秒（别卡满 15 秒，留余量给转场）

## 常见陷阱

- 文件过多但未明确每个素材的角色
- 遗漏身份/服装/道具的连续性指令
- 混淆目标总时长与延长时间
- 请求可能被政策拦截的写实人脸（即梦平台）
- 使用系列名、角色名或品牌近似词（触发审核拒绝）
- 过于接近可识别的标志性特征
- 从参考图中保留品牌 Logo 或商标而未明确去除
- 不为可推断的 IP 引用添加负面约束
- 提示词超过 200 字导致生成失败
- 首尾帧主体位置和姿态不合理导致衔接断裂

## 快速验证清单

- [ ] 文件数量和大小限制已遵守（总≤12，图片≤9，视频≤3，音频≤3）
- [ ] 混合文件总数 ≤ 12
- [ ] 时长在 4 到 15 秒之间
- [ ] 每个参考素材都有明确的 `@asset` 角色
- [ ] 提示词包含五维度信息（镜头/物理/情感/光影/节奏）
- [ ] 必要时包含负面约束
- [ ] 提示词和素材描述中无系列名、角色名、品牌名
- [ ] 负面约束明确列出所有可推断的 IP 引用
- [ ] 角色/生物使用完全原创的名称和独特视觉特征
- [ ] 对白和音效作为视觉动作的独立层级写入
- [ ] 多段视频有明确的交接帧描述
- [ ] 镜头术语与 `camera-and-styles.md` 词汇表一致
- [ ] 提示词总长度 ≤ 200 字
