## 第一部分：输出格式硬门

### 完整文件顺序（区块名逐字使用）

```markdown
# 《剧本名》｜视频类型｜媒介｜画幅

## 使用的 @资产清单
人物：@角色名 ...
场景：@场景名 ...
道具：@道具名 ...

## 状态资产引用
使用正式状态资产：... / 无。
使用临时状态引用：... / 无。
建议补做状态资产：... / 无。
临时资产引用说明：当前为临时资产引用版，建议后续补做正式多状态资产库。 / 不适用。

## 参数确认
- 画幅比例：...
- 视频类型：...
- 媒介/视觉风格：...
- 音频参考：未提供 / 已提供并列出引用名
- 资产模式：严格资产库 / 临时资产引用

## 全局风格提示词
风格锁定：媒介来源，渲染方式，角色质感，运动质感，材质语言，光影色彩。
特殊风格化：不启用。 / 启用；作用范围、进入方式、退出方式和现实层保持规则。

## 角色音色设定
@角色名：年龄与声线；语速与断句；音量范围；气息与咬字；情绪底色；禁止项。

## 第1组：组标题
本组剧情：...
人物空间站位：...
空间承接：...（仅需要时输出）
环境：...

镜头1（0-X秒）：
一个按发生顺序书写的完整自然段。

约束：有音效，无音乐，无字幕。
本组末尾空间状态：...
视频时长：X秒
```

### 区块说明

#### 全局风格提示词

`风格锁定` 只锁六项底层质感：
1. 媒介来源
2. 渲染方式
3. 角色质感
4. 运动质感
5. 材质语言
6. 光影色彩

**禁止写入风格锁定**：
- 画幅
- 视频类型
- 分镜密度
- 具体焦段包
- 摄影机路线
- 剧情动作
- 对白
- 字幕
- 水印
- 单组环境事实

`特殊风格化` 必须二选一：
- 不启用
- 启用；作用范围、进入方式、退出方式和现实层保持规则

#### 角色音色设定

每个主要人物单独一行，即使在本剧本中保持静默也要有音色行。

音色只写跨场景稳定底色。受伤喘息、本句喊叫、句尾发抖等临场表演紧跟对应台词写入镜头，不污染基础音色。

**音色样例**：
```
@林岚：成年女性，中低音区，声线清晰而略带干涩；常速偏克制，句间停顿明确；
日常中等音量，强调时短暂提高；浅呼吸，咬字利落；长期警觉，情绪不轻易外露；
禁止卡通腔、无因由耳语、夸张哭腔和音高漂移。
```

#### 组内结构

顺序固定：
1. `本组剧情`
2. `人物空间站位`
3. `空间承接`（仅需要时）
4. `环境`
5. 各镜头
6. `约束`
7. `本组末尾空间状态`
8. `视频时长`

**`本组剧情`**：40-90 字，只写可见事件，不复述台词。

**`人物空间站位`**：写本组**起始时刻**在场快照，必须列入全部在场人物，包括本组无动作无台词的旁观者。

**`本组末尾空间状态`**：写本组**结束瞬间**可继承状态。

**承接等式**：上一组末尾空间状态的在场人物集合 = 下一组人物空间站位的起手人物集合。

**`约束`**：逐字输出 `约束：有音效，无音乐，无字幕。`

## 第二部分：镜头自然段写法

### 核心原则

每个镜头标题下只写**一个连续自然段**，按镜头内真实发生顺序融合：

```
媒介化视觉起点与景别 → 摄影机或观察点 → 人物和道具初态 → 第一动作或运镜
→ 原台词在开口时刻出现 → 倾听、接触、受力、结果和反应 → 声光在触发点变化 → 可继承末态
```

**禁止**：
- ❌ 先堆全部视觉信息再分批补动作、对白和声光
- ❌ 使用旧标签：`画面：` `镜头：` `运镜：` `动作：` `台词：` `光线：`
- ❌ 用分号伪装成旧字段顺序
- ❌ 输出 `镜头目的` `标点节奏重点` `微表情` `构图取景` `焦点景深` `机位` 等独立标签
- ❌ 输出任何分析、账本、密度判断、自检过程

### 时间码规范

- 标题格式 `镜头N（起-止秒）：`
- 起止只能是**整数秒**
- 从 0 连续递增
- 不重叠、不倒退、不留无说明空档
- 最后一个镜头的结束秒必须等于组时长
- 每组镜头编号都从 `镜头1` 重新开始

### 每镜四项事实（缺一不可）

1. **视觉起点**：景别与焦段或等效透视
2. **观察关系**：摄影机或观察点相对主体的位置、朝向
3. **构图落位**：主体画面位置、前后景、遮挡、画面填充
4. **摄影机状态**：明确写出有目的的固定，或含三要素的主动运镜

同机位连续承接可写"延续上一镜固定机位"，但不得省略摄影机状态。

### 台词写法

- 原台词与原标点逐字嵌入，一字不改
- 放入规范中文引号 `"……"`
- 说话人与表演说明留在引号外
- 在人物**真正开口的时刻**插入，不提前不延后
- 每句后按需留出反应时间
- 明示发声方式：现场口型、画外、旁白、电话、录音、设备播报
- 无台词镜头明写"无人开口"或"全程无人说话"
- 引号内绝不添加 `@`

**台词样例**：
```
@林岚 盯住老周右手中的钥匙，林岚压低声音说："你为什么骗我？"
@老周 没有回答，老周把 @钥匙 放到 @金属桌面，钥匙触桌发出清脆碰响。
```

## 第三部分：空间措辞硬门

### 禁止模糊方位词

**禁止使用**：
- `一侧`
- `一边`
- `另一侧`
- `另一边`
- `某侧`
- `某边`
- `斜侧`
- `侧前方`
- `门边`
- `桌旁`
- `不远处`
- `适当距离`

### 可用方位词（必须带参照）

`前方`、`后方`、`左`、`右` 必须带明确参照主体。

`旁边`、`靠近`、`外侧` 只有同时给出固定锚点与接触或身体尺度关系时才可用。

### 禁止输出

- 米、厘米、毫米
- 小数距离
- 东南西北罗盘方位
- `全画幅` 或 `全画幅等效` 字样
- `虚拟镜头`

### 焦段写法

焦段只写简写视觉锚点：
- `24mm广角视角`
- `50mm标准视角`
- `65mm中焦视角`
- `85mm长焦视角`

写数值焦段时数值后必须紧跟景别：
- `65mm中景`
- `85mm近景`

对应关系：
- ≤24mm → 大全景
- 25-35mm → 全景
- 36-55mm → 中景
- 56-79mm → 中近景
- 80-120mm → 近景
- 121-200mm → 特写
- >200mm → 大特写

### 用画内关系代替精确尺寸

✅ 正确：
- `镜头贴近地面`
- `略高于@林岚视线`
- `两人伸手即可触及@密码箱`
- `以@密码箱为前景对准库门把手`

❌ 错误：
- `距离 2.5 米`
- `左侧 3 米处`

### 视听术语双语

正文中的景别、运镜、角度、视角类专业名词写作 `中文（English）`，同一术语每组只在该组首次出现时附英文。

常用对照：
- 大全景（extreme long shot）
- 全景（full shot）
- 中景（medium shot）
- 中近景（medium close-up）
- 近景（close-up）
- 特写（close-up detail）
- 固定机位（static shot）
- 推近（push in）
- 拉远（pull out）
- 摇（pan）
- 横移（truck）
- 跟拍（tracking shot）
- 升起（crane up）
- 环绕（orbit）
- 手持（handheld）
- 低角度（low angle）
- 高角度（high angle）
- 俯视（overhead shot）
- 荷兰角（Dutch angle）
- 主观视角（POV）
- 过肩（over-the-shoulder）
- 升格（slow motion）
- 深焦（deep focus）
- 长镜头（long take）

术语括号内的英文不计入每镜"英文专业视觉锚点最多 2 个"的上限。

## 第四部分：人物指代硬门

### 禁止人物代词

除原台词引号内部外，正文**禁止人物代词**：
- `我`
- `你`
- `您`
- `他`
- `她`
- `他们`
- `她们`
- `本人`
- `其`
- `对方`
- `自己`

**必须重复明确姓名或资产名**。

### 适用范围

- 双人对话
- 多人场面
- 接触
- 受力
- 道具争夺
- 视线切换

发起者、承受者、持有人、观察者都写明确姓名。

画外声、录音、电话声也写明确说话人或已登记声音别名。

### 豁免

**原台词及原标点完整豁免**。引号内出现"我、你、他、她"原样保留。

### 代词不得继承

代词不得从以下位置继承：
- 参数
- 资产清单
- 上一字段
- 上一镜头
- 上一组

## 第五部分：资产引用

### @token 使用规则

只使用已声明的 token。

`@token` 用于需要精确绑定时；已建立且无歧义的人物、场景、道具可直接写规范名称，不因分组或镜头边界重复加 `@`。

多个相似道具同时存在时不得缩写成无法区分的名称。

`@token` 后用空格或标点断开，不粘连方位词或动作词。

### 状态资产

状态资产只描述当前静态视觉差异。

生命周期如：`@密码箱_闭合 → 可见开锁掀盖 → @密码箱_开启`

未登记状态不得通过长后缀或同义词伪装成合法资产。

姿态不等于伤情。外显状态与真实状态必须区分。

不得把动作历史拼进 token 名（`@箱_开启后又关闭` 非法）。

### 复杂交互

复杂身体接触、持物、跌落、武器轨迹、道具交接时，每个状态必须继承可见的前一状态，不得声明未展示的结果状态。

占手道具持续约束抓握、平衡和可用肢体，同一肢体的先后动作不得伪装成同时发生。

## 第六部分：光影与声音

### 持续光源与环境声

持续光源与持续环境声只在 `环境` 行写一次，镜头内不重复，只在改变、被遮断或成为焦点时重提。

### 瞬时声与短暂光源

瞬时声紧跟触发动作。

短暂剧情光源（手机亮起、手电扫过、车灯、闪电、屏幕弹窗）只在实际触发时刻写入镜头，不进 `环境` 行。

### 光源规则

固定光源不得无原因闪烁、改向或追随人物。

人物或道具移动造成的变化写成遮挡、反射、掠光、曝光响应。

新光源有明确来源和触发动作，变化时刻与触发时刻一致。

`画面渐黑` 不等于场内灯具熄灭。

### 声音因果

声音反应必须发生在声源触发之后。

**样例**：
```
@卷帘门锁扣 先发出一次金属弹响，@林岚 听到声音后转头，
门缝随后被外力撑宽，走廊冷光才扩大到地面。
```

## 第七部分：媒介翻译表

| 媒介 | 内部推演 | 正文输出 |
|---|---|---|
| 真人写实 | 真实可达机位、全画幅等效视角、合理景深、快门与对焦能力 | 简写焦段视角 + 可见机位关系；光线服从实际存在或明确建立的光源 |
| 写实3DCG | 虚拟摄影机、等效视角、景深、运动模糊、PBR、全局光照、体积效果 | 简写焦段视角 + 可见观察关系；虚拟机位仍服从叙事空间、遮挡与轴线 |
| 风格化3DCG | 等效透视、轮廓、比例、材质风格、分层光、动画节奏 | 等效透视 + 风格化描述；只在明确模拟真实摄影时才锁定光圈与真实散景 |
| 2D | 景别、构图、前中后景分层、角色落位、背景软化、层间视差、关键帧节奏 | 景别 + 图层层次；说明运动来自画面裁切、图层位移、背景视差还是角色动画；焦段只作等效透视，不强制真实光圈与焦外 |

### 共同保留

所有媒介共同保留：
- 景别
- 观察点
- 画面落位
- 焦点目标
- 层次
- 动作时序
- 对白时机
- 声光因果
- 镜头末态

### 术语区分

- **焦点转移**：对焦平面改变
- **等效视角收紧**：透视覆盖范围改变

两者不可混用。

不把浅景深默认叠加到快速位移、多人接触或关键道具轨迹上，可读性优先。

## 第八部分：体量控制

- 每组不超过 **1800 汉字**
- 每镜只承担一个主要目的
- 环境细节最多 2 项
- 身体姿态锚点最多 3 个
- 英文专业视觉锚点最多 2 个

### 压缩优先级

1. 重复光线词
2. 重复镜头词
3. 格式冗余

**不可压缩**：
- 关键动作
- 原台词
- 口型停顿
- 空间站位
- 情绪转折
