# 运镜设计系统 v6.0.0

> 整合自 Elio_AIGC Seedance 2.0 Prompts V2.3（SKILL制作者：B站/抖音：Elio_AIGC）

---

## 核心原则

**每组至少 1 个主动运镜镜头。主动运镜三要素缺一不可。**

固定机位必须有稳定观察或可读性上的实际任务，不是默认值。

---

## 主动运镜三要素（缺一不可）

1. **起始观察点** — 摄影机或观察点相对主体的位置
2. **运动轨迹方向** — 摄影机怎么动
3. **停止结果** — 停在谁身上、什么景别、看到什么

**未写运镜 ≠ 固定机位**。如果写了运动但没有三要素，视为无效运镜。

---

## 运镜功能表

| move | 叙事功能 | 方向段写法 | 最小时长 |
|---|---|---|---|
| `fixed` | 对峙/阅读/微表情/压制 | — | 按对白或读取 |
| `fast_push_in` | 破门/冲撞/惊变 | 向前快速推近 | ≥1s |
| `push_in` | 逼近/压迫升级 | 向前推近 | ≥1s |
| `slow_push_in` | 揭露/点破/凝视 | 缓慢向前推近 | **≥3s** |
| `follow` | 报信/人物冲入 | 跟随 @X 向前跟拍 | ≥1s |
| `track` | 落座/连续移动 | 横向侧跟 @X | ≥1s |
| `pan` | 视线转移/发现 | 摇向 @X | ≥1s |
| `rise` | 登场揭示（脚→脸） | 缓慢向上升起 | **≥3s** |
| `pull_back` | 收尾/疏离/全景 | 缓慢向后拉远 | **≥3s** |
| `arc` | 关系重组（仅开阔空间） | 绕 @X 缓慢弧形环绕 | **≥3s** |

## 关键规则

### 每组至少 1 个主动运镜

固定机位必须有实际任务：
- 纯读取
- 短促反应
- 微表情
- 对峙压制

以下情况必须重新评估运镜：
- 发现
- 递交
- 视线转移
- 人物移动
- 关系重组
- 情绪升级

### 缓慢运镜 ≥ 3 秒

含以下关键词的镜头必须 ≥ 3 秒：
- 缓慢
- 慢速
- 徐徐
- 慢推
- 慢摇
- 慢移
- 渐近
- 渐远

### 每镜最多 2 个运动分量

不要在一个镜头内塞入过多运动。

### 狭窄空间限制

狭窄空间（走廊、车内、堂屋、电梯）**禁用**：
- 环绕（arc）
- 弧轨

改用：
- 侧跟（track）
- 横移（truck）

### 起始观察点用词

**可用**：
- 门槛内 / 门槛外
- 肩后
- 前方 / 后方
- 左侧 / 右侧
- 高处 / 低处
- 平视 / 仰视 / 俯视
- 略高于 / 略低于
- 接 `@资产` 精确锚点

**禁止**：
- 模糊方位词（一侧、某侧等）
- 米、厘米、小数距离

### 语法规范

**「摄影机」与运动动词之间不得插入逗号**。

✅ 正确：`跟随 @阿豹 向前跟拍`
❌ 错误：`跟随, @阿豹, 向前跟拍`

`@token` 与运动动词之间必须有空格。

## 叙事信号选型

| 情境 | 推荐运镜 |
|------|---------|
| 情绪压力升级或点破真相 | `slow_push_in` |
| 破门冲撞 | `fast_push_in`（低角度仰视更有冲击） |
| 人物冲入报信 | `follow` |
| 进门落座 | `track` |
| 视线转向新人物或证据 | `pan` |
| 新角色登场由物到人 | `rise` |
| 一场结束抽离 | `pull_back` |
| 对峙问答阅读屏幕 | `fixed` |

## 运镜主轴

每场登记一次运镜主轴，选 1 种主运镜、0-2 种辅助运镜，该场各组共享。

### 六种运镜主轴

| 主轴 | 适用场景 | 主运镜 | 辅助运镜 |
|------|---------|--------|---------|
| 稳定观察 | 对话、信息交代 | `fixed` | `push_in` |
| 逐渐逼近 | 压迫升级、真相揭示 | `push_in` / `slow_push_in` | `pan` |
| 逐渐疏离 | 收尾、孤独感 | `pull_back` | `fixed` |
| 跟随行动 | 追逐、报信、移动 | `follow` / `track` | `pan` |
| 空间揭示 | 新场景建立、登场 | `rise` / `pan` | `track` |
| 群像压迫 | 多人对峙、包围感 | `arc` / `track` | `push_in` |

## 句式样例

### 固定机位

```
65mm中景（medium shot），正对 @金属工作台 中线的固定机位（static shot），
@林岚 与 @老周 分居画面左右，@密码箱_闭合 居中压住对称轴；
老周没有让路，林岚向中线挪近半步，两人视线在箱体上方相撞，
固定构图持续显示双方距离被压缩。
```

### 主动运镜

```
85mm面部近景（close-up），摄影机从 @老周 肩后与 @林岚 视线齐平的观察点
缓慢向前推近（push in），镜头停在林岚眼部，林岚始终位于画面右侧三分线；
林岚听见箱内异响后收紧下颌。
```

**要素检查**：
- ✅ 起始观察点：@老周 肩后与 @林岚 视线齐平
- ✅ 运动轨迹方向：缓慢向前推近
- ✅ 停止结果：停在林岚眼部
