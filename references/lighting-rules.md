# 光源规则 + 风格块系统（Lighting Rules + Style Block System）

> 来源：shotlist-builder reference/STYLE_BLOCK.md
> 核心原则：**严格仅使用场景内实际存在的光源（practicals）**。禁止一切电影补光。

---

## 一、Practicals-Only 规则（严格实际光源）

### 核心规则（每个提示词必须包含）

```
灯光：⚠️严格仅使用场景内实际存在的光源（practicals）——屏幕、显示器、办公舱内部灯光、窗户、实用吊灯/台灯等。
禁止一切电影补光——禁正面光、禁侧面补光、禁顶光、禁底光、禁反光板、禁柔光箱、禁LED灯带、禁霓虹、禁任何画面外光源。
摄影机始终在人物的阴影侧（shadow side）拍摄——面部自然受光但从较暗的一侧取景，practicals环境光照亮脸部轮廓和眼神光（catchlight）。
全程大气薄雾haze增加空气质感——禁止可见光束（god rays）。
```

### 摄影机阴影侧规则

- 摄影机**始终**在人物的**阴影侧**拍摄
- 面部自然受光但从较暗的一侧取景
- practicals 环境光照亮脸部轮廓和眼神光（catchlight）
- 这不是可选的——这是每个提示词的强制规则

### 屏幕/显示器特殊规则

当场景中有屏幕/显示器在画面内时，额外追加：

```
⚠️禁止屏幕/显示器向环境投射可见蓝色光芒——屏幕仅作为背景元素发光，不作为主光源。
⚠️禁止蓝色色溢（blue spill）打在人物皮肤和服装上。
```

---

## 二、60:30:10 色彩比例规则

### 基本公式

```
色彩：60:30:10——主色/辅色/点缀色。
```

### 按情绪匹配色彩比例

| 情绪/氛围 | 60% 主色 | 30% 辅色 | 10% 点缀色 |
|-----------|---------|---------|-----------|
| **冷冲突/紧张** | 冷蓝 cool blue | 混凝土灰 concrete grey | 红色点缀 red accent |
| **温暖/亲密** | 暖钨丝 warm tungsten | 深棕 deep brown | 琥珀 amber |
| **危险/恐慌** | 深红 deep red | 黑色 black | 钠灯橙 sodium orange |
| **科幻/科技** | 黑色 black | 冷灰 cool grey | 点缀色（紫/青）accent (purple/cyan) |

### 输出格式

在提示词中显式声明比例：

```
色彩：60:30:10——冷蓝/混凝土灰/红色点缀。
```

## 三、完整风格块模板（Canonical Style Block）

以下风格段落追加到**每个**提示词末尾，除非用户上传了自定义风格覆盖。

### 完整模板

```
风格：8K IMAX。超写实——禁3D渲染，禁游戏引擎，禁游戏CG过场质感。摄影：Emmanuel Lubezki × Roger Deakins。灯光：⚠️严格仅使用场景内实际存在的光源（practicals）。禁止一切电影补光——禁正面光、禁侧面补光、禁顶光、禁底光、禁反光板、禁柔光箱、禁LED灯带、禁霓虹、禁任何画面外光源。摄影机始终在人物的阴影侧（shadow side）拍摄。全程大气薄雾haze——禁止可见光束（god rays）。色彩：60:30:10——主色/辅色/点缀色。镜头：物理电影镜头。180°快门运动模糊。皮肤：毛孔级写实——汗毛、不对称痣、毛细血管潮红、毛孔阴影匹配现场光源。表演：好莱坞级——反应前微停顿、精准视线、湿润活眼带眼神光、可见呼吸和胸腔起伏。物理：重力惯性真实——质量有真实重量、正确接触阴影。禁漂浮道具。构图：三分法+黄金比例。每人从第一帧开始运动。连续性：角色、道具、环境每个镜头完全一致。禁身份漂移。技术：60fps流畅运动。8K细节。禁抖动（除手持呼吸感）。音频：仅环境SFX。禁音乐。禁字幕。
```

### 风格块各段解析

| 段落 | 内容 | 关键约束 |
|------|------|---------|
| **风格** | 8K IMAX，超写实 | 禁 3D 渲染、禁游戏引擎、禁 CG 过场 |
| **摄影** | Lubezki × Deakins | 自然光 + 控制剪影 |
| **灯光** | practicals-only | 禁一切电影补光，摄影机在阴影侧 |
| **色彩** | 60:30:10 | 主色/辅色/点缀色 |
| **镜头** | 物理电影镜头 | 180° 快门运动模糊 |
| **皮肤** | 毛孔级写实 | 汗毛、不对称痣、毛细血管潮红 |
| **表演** | 好莱坞级 | 反应前微停顿、精准视线、湿润活眼 |
| **物理** | 重力惯性真实 | 质量有真实重量、禁漂浮道具 |
| **构图** | 三分法 + 黄金比例 | 每人从第一帧开始运动 |
| **连续性** | 完全一致 | 禁身份漂移 |
| **技术** | 60fps + 8K | 禁抖动（除手持呼吸感） |
| **音频** | 仅环境 SFX | 禁音乐、禁字幕 |

## 四、场景类型变体（Scene-Type Lighting Variants）

以下变体**叠层**到基础 practicals-only 规则之上，根据场景类型选择：

### 4.1 夜景室内 — 自然光（如：黑暗公寓，无灯开启）

```
灯光：夜景——室内全部灯光关闭，禁任何室内光源（禁灯、禁台灯、禁屏幕光），整个空间唯一的光来自窗外城市夜景透过窗户洒入的冷蓝光。摄影机始终在人物的阴影侧拍摄。
```

### 4.2 地下基地 / 科幻室内 + practicals

```
灯光：⚠️严格仅使用场景内实际存在的光源（practicals）——屏幕、工作站显示器、玻璃办公舱内部灯光。禁止一切电影补光。⚠️禁止屏幕/显示器向环境投射可见蓝色光芒——屏幕仅作为背景元素发光。主要照明来自玻璃办公舱内暖白灯光和工作台台灯的漫反射。摄影机始终在人物的阴影侧（shadow side）拍摄。⚠️禁止蓝色色溢（blue spill）打在人物皮肤和服装上。
```

### 4.3 日外（Day Exterior）

```
灯光：仅自然日光——硬阳光+大气散射，摄影机始终在人物的阴影侧（shadow side）拍摄，contre-jour逆光从天空方向，禁反光板、禁补光、禁柔光箱。全程大气haze增加深度。
```

### 4.4 夜外（Night Exterior）

```
灯光：仅实际街灯、车头灯、店铺霓虹反射、路灯。无任何摄影补光。摄影机在人物阴影侧。全程城市haze。
```

### 4.5 暖室内（Warm Interior — 厨房、卧室有台灯）

```
灯光：仅室内实际灯光——温白色台灯、吊灯、暖色practicals。摄影机始终在阴影侧。无任何外部补光。haze轻微。
```

## 五、禁用列表（Forbidden List）

### 渲染禁用

| ❌ 禁止 | 原因 |
|--------|------|
| 3D 渲染 | 破坏超写实质感 |
| 游戏引擎 | 产生 CG 过场动画感 |
| 游戏 CG 过场质感 | 非电影感 |
| 霓虹 | 过于风格化，破坏 practicals 规则 |
| 过饱和色 | 不自然 |
| HDR 感 | 过度假，不真实 |

### 灯光禁用

| ❌ 禁止 | 原因 |
|--------|------|
| 正面光 frontal key | 破坏阴影侧规则 |
| 侧面补光 fill light | 非 practicals |
| 顶光 top light | 非 practicals |
| 底光 bottom light | 非 practicals |
| 反光板 reflector | 非 practicals |
| 柔光箱 softbox | 非 practicals |
| LED 灯带 | 非 practicals |
| 霓虹光源 | 非 practicals |
| 画面外光源 | 非 practicals |
| 可见光束 god rays | haze 可以有，光束不行 |
| 蓝色色溢 blue spill | 屏幕光不应投射到皮肤 |

### 技术禁用

| ❌ 禁止 | 原因 |
|--------|------|
| 光学畸变 | 桶形/枕形/鱼眼破坏画面 |
| 漂浮道具 | 物理不真实 |
| 身份漂移 | 角色在不同帧间外貌变化 |
| 抖动（除手持呼吸感） | 非情绪驱动的抖动 |
| 音乐（除非要求） | 仅环境 SFX |
| 字幕（除非要求） | 纯视觉叙事 |

## 六、结尾格式

### 标准结尾

每个提示词以以下格式结尾：

```
15秒。21:9。
```

### 多镜头提示词

对于包含内部剪辑的提示词（`【镜头1】【镜头2】【镜头3】`），仍然 15 秒总计——在内部按各镜头时长规则分配。

### 画幅比覆盖

如用户指定不同画幅比（如 9:16 竖屏短视频、4:3 复古），替换 `21:9`：

```
15秒。9:16。
```

---

## 七、广角镜头附加规则

对于全景和任何使用 35mm 或更广镜头的拍摄，追加：

```
禁光学畸变——禁桶形畸变、禁枕形畸变、禁鱼眼效果、禁广角变形，画面线条必须笔直，构图平整。
```

---

## 八、多镜头提示词头部

当提示词包含内部剪辑（`【镜头1】【镜头2】` 等）时，在开头追加：

```
多机位剪辑（multi-shot）。
```

当提示词为连续单镜头时，在开头追加：

```
单镜头（one-shot，无剪辑）。
```

---

## 九、风格锚点速查

当需要简洁的风格指示时，使用以下紧凑锚点：

| 风格 | 锚点 |
|------|------|
| 自然光手持 | Lubezki natural-light handheld |
| 控制剪影 | Deakins controlled silhouette |
| 亲密广角 | Cuarón intimate wide |
| 侧面脸部表演 | Bergman profile face acting |
| 慢走极简主义 | Refn slow-walk minimalism |

**避免**过长的影迷链条（cinephile chains），只添加噪声。
