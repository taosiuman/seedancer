# 重拍协议 (Retake Protocol) — Seedance 2.5

> 生成不是终点，是评估的起点。
> 🆕 v4.0.0：新增"局部编辑"判定，适配 Seedance 2.5 编辑能力。

---

## 六判定取景（v4 新增"局部编辑"）

| 判定 | 适用场景 | 下一步 |
|------|----------|--------|
| **保留** | 核心目标达成，无致命问题 | 锁定，进入下一镜头 |
| **后期修复** | 问题在后期能解决（调色/音效/文字） | 不要重拍，交给后期 |
| **🆕 局部编辑** | 只有局部元素有问题，整体可保留 | 用 Edit 模式精准修改 |
| **重生成** | 提示词对，但运气不好（采样方差） | 同提示词，新种子。最多 2-3 次 |
| **重写** | 同一问题出现 2 次以上 | 系统性问题，诊断机制，改提示词 |
| **换模式** | 当前模式无法满足需求 | 尝试其他生成模式 |

---

## 何时选择"局部编辑"而非"重生成"

| 条件 | 选择 |
|------|------|
| 整体构图/运动/光影都 OK，只有 1-2 个元素不对 | ✅ 局部编辑 |
| 90% 画面满意，只有背景/商品/文字需修改 | ✅ 局部编辑 |
| 需要保持精确的镜头运动轨迹 | ✅ 局部编辑 |
| 广告需要多版本（不同 SKU/语言/背景） | ✅ 局部编辑 |
| 整体构图/光影/运动都不对 | ❌ 重新生成 |
| 提示词本身有系统性错误 | ❌ 重写提示词 |

---

## 单变量规则

**每次只改一个东西**：
- 改一个提示词片段，**或**
- 改种子，**或**
- 改模式，**或**
- 改一个参考素材

同时改两个东西，结果无法解读。

---

## 尝试预算

**第一次生成前就设定预算**：
- 标准尝试次数：5 次
- 快速草稿：10 次
- 书面定义"够好"：核心目标达成，次要问题可接受

**预算过半无进展** → 停止迭代，换策略：
- 换模式（T2V→I2V/R2V）
- 拆分镜头
- 使用局部编辑替代重生成 🆕
- 承认这个想法不行

---

## 镜头日志

每次尝试记录一行：

```
尝试 N · 改了：[单变量] · 种子：[相同/新] · 判定：[保留/后期/局部编辑/重生成/重写/换模式] · 证据：[一句话]
```

两次相同问题 → 重写，不试第三次。

---

## 诊断流程

```
生成结果不满意
    ↓
问题是什么？
    ├── 核心目标未达成 → 诊断机制 → 重写
    ├── 核心目标达成，有小问题 → 
    │   ├── 问题能在后期修？ → 后期修复
    │   ├── 问题在局部区域？ → 🆕 局部编辑
    │   └── 问题全局性？ → 
    │       ├── 提示词对，运气差 → 重生成（换种子）
    │       └── 提示词错 → 重写
    └── 模式不对？ → 换模式
```

## Seedance 2.5 新增诊断

| 症状 | 可能原因 | 判定 | 修复 |
|------|----------|------|------|
| 背景有不该出现的元素 | 参考出血/提示词遗漏 | 🆕 局部编辑 | 框选背景区域替换 |
| 商品颜色偏差 | 参考未锁定 | 🆕 局部编辑 | 指定时间段替换商品 |
| 文字乱码 | 文字渲染问题 | 🆕 局部编辑 或 后期 | 重新描述文字/后期叠加 |
| 整体"油腻感" | 材质描述模糊 | 重写 | 添加具体材质描述（机制 9） |
| 多人场景身份混乱 | 参考过多/角色未分配 | 重写 | 为每个角色分配明确角色 |
| 30秒后半段质量下降 | 注意力衰减 | 拆分 | 分为两个 15 秒段 |
