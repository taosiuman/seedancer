# 表演微节拍目录（Performance Micro-Beats Catalog）

> 来源：shotlist-builder reference/MICRO_BEATS.md + hellgrind ACTING SKILL.md
> 核心原则：**永远不要在提示词里留一个笼统的情绪词**。每个情绪方向必须分解为具体的肌肉运动、呼吸、眼神和皮肤变化。

---

## 一、基础规则

当用户（或剧本）写"角色看起来[笼统情绪]"——**停下来。分解它**。如果无法自信地分解，请用户选择变体。

### 澄清示例

当用户写"惊讶"时，提供选项：

> *哪种惊讶？*
> *(a) 轻度正面惊讶 — 眉毛上扬、嘴唇微张、瞳孔扩张 0.3 秒、柔和鼻吸气。无多余动作。*
> *(b) 震惊 — 急促口吸气、双眼睁大、身体冻结、一只手不自主抬至胸前。*
> *(c) 不信 — 缓慢眨眼、头部微侧倾、嘴唇收紧、只有一侧眉毛抬起。*
> *(d) 惊喜 — 眼睛点亮（眼神光强化）、笑容逐步建立、双肩放松。*
> *哪种合适？*

同样适用于"紧张"、"悲伤"、"愤怒"、"害怕"、"沉思"、"恋爱中"——每个笼统形容词有 3-5 种不同的物理实现。

## 二、按情绪分类的微节拍目录

### 愤怒 / 决心 / 暴怒（Anger / Determination / Rage）

```
- 颊部咬肌（masseter）通过皮肤可见地搏动
- 颈部颈动脉脉搏可见
- 太阳穴血管浮起
- 鼻翼在重音词上扩张
- 瞳孔收缩（focus tightening）
- 眼角外缘收紧（genuine intensity，非廉价眯眼）
- 高潮时刻不眨眼
- 眉骨/鼻翼处微汗珠
```

**关联身体状态**：
- 重心偏高（胸部、下巴——自信/攻击性）
- 快速/破碎的节奏（神经质能量）
- 方肩、张开的手掌 vs 握拳
- 呼吸高而急促

### 焦虑 / 紧张（Anxiety / Nervousness）

```
- 一次喉结上下吞咽（visible swallow）
- 台词前一次短促浅吸气（短促鼻吸）
- 用舌头舔润干燥的下唇
- 下唇轻微内收
- 脸颊毛细血管充血泛红
- 关键词上瞳孔扩张
- ⚠️除非明确说明，否则不哭
```

**关联身体状态**：
- 频繁的自触摸（脸、头发）
- 破碎的语言、填充笑声
- 用眼睛请求许可
- 呼吸高而急促（恐慌）

### 悲伤 / 脆弱（Sadness / Vulnerability）— 不流泪版

```
- 眼角外缘下垂
- 眼睛湿润带眼神光（wet with catchlight）——但⚠️不流、不淌、不闪烁泪光
- 眉头中央皱起（corrugator muscle）
- 嘴唇轻微颤抖
- 头部微微低垂
```

**关联身体状态**：
- 重心低（肩膀下沉、驼背——疲劳/恐惧/服从）
- 缓慢/经济的节奏
- 交叉双臂、低头、封闭姿态
- 呼吸低而缓慢

### 控制 / 平静 / 优越（Control / Calm / Superiority）

```
- 平稳均匀的呼吸（与紧张的对手形成对比）
- 手指/手臂放松
- 缓慢均匀的眨眼（slow blink）
- 下颌微抬（chin lift）
- Duchenne微笑——眼角外侧出现细纹。⚠️逐渐建立，不是从已完成的状态开始
```

**关联身体状态**：
- 高地位身体语言：不动的头、缓慢的动作、长久的注视、回答前的停顿、占据空间
- **最危险的人动得最少**
- 呼吸低而慢（控制）

### 沉重 / 负重（Heaviness / Weighed-down）

```
- 双肩下沉（heavy shoulders）
- 头部微微下垂
- 深而缓慢的呼吸
- 声音比平时更低沉、更闷
- 回答时头部轻微侧倾（5–15°）
```

### 震惊 / 冻结（Shock / Freeze）

```
- 镜头开始瞬间——身体冻结0.3-0.5秒，无任何移动
- 瞳孔在冻结瞬间扩张
- 嘴唇微微张开（lips part）但无声
- 一次延迟的、急促的鼻吸气在freeze结束后
- 眼睛锁定在触发源上——无眨眼、无视线偏移
```

### 压抑情绪（Suppressed Emotion）— 最难的——物理抵抗

```
- 他在试图忍住——每一块面部肌肉都在对抗涌上来的情绪
- 颧骨处咬肌慢慢收缩
- 喉结一次延迟的、用力的吞咽
- 眼睛逐渐湿润，眼眶积聚泪水使眼球开始泛光——但泪不落下
- 一次缓慢、深、控制的吸气——胸腔可见起伏
- 下颌微抖一次——立刻被收紧
```

## 三、惊讶变体（Surprise Variants）

### 轻度正面（Light Positive）
```
- 眉毛轻微上扬
- 嘴唇微张
- 瞳孔扩张约0.3秒
- 一次柔和的鼻吸气
- 无其他多余动作
```

### 震惊（Shock）
```
- 急促的口吸气（sharp mouth inhale）
- 双眼睁大，瞳孔扩张
- 身体冻结在原地
- 一只手不自主抬至胸前
- 嘴唇微微张开但无声
```

### 不信（Disbelief）
```
- 一次缓慢的眨眼
- 头部微微侧倾
- 嘴唇收紧
- 只有一侧眉毛抬起
- 视线锁定在触发源上
```

### 惊喜（Surprise + Joy）
```
- 眼睛点亮（catchlight强化）
- 笑容逐步建立——⚠️不是瞬间出现的完整笑容
- 双肩放松下沉
- 一次轻松的呼气
```

## 四、台词前后节拍（Dialogue Beats）

每句台词获得三个部分：

### Pre-line Beat（台词前）
第一个字之前发生什么：吞咽、吸气、舔唇、姿态变化

### Mid-line Emphasis（台词中）
哪些词通过鼻翼、语调、瞳孔强调

### Post-line Beat（台词后）
~0.5 秒屏息，然后释放

### 完整示例

```
台词前：一次短促鼻吸气，喉结一次吞咽。
台词："Don't ask me again."——重音落在"again"，鼻翼在该词上扩张。
台词后：保持视线锁定在对手身上0.5秒——然后微微移开。
```

## 五、情绪弧线（单镜头内的情绪变化）

当情绪在一个连续镜头内变化时，写成编号序列，每个节拍有明确的肌肉/呼吸/眼神变化：

```
①开始——[情绪A]——[具体肌肉指标]
②过渡——[触发事件]——[哪些肌肉释放/收紧]
③下一阶段——[情绪B]——[新指标]
④...
⑦结尾——[最终情绪]——[最终指标]
```

同时显式说明**整个弧线中面部必须保持可见的部分**（眉毛、下颌、呼吸、眼神）。

将每个编号节拍绑定到对应的摄影机阶段（见 camera-emotion-sync.md §2）。

## 六、虚焦听众的微动作规则（Listeners in Bokeh）

当焦点角色在焦内、其他角色虚焦时——**他们不是静止的**。必须写出：

1. **头部和视线方向** — 他们看哪里
2. **肩膀和头部的微动作** — 虚焦中也有生命
3. **对关键时刻的反应** — 即使在虚焦中
4. **明确的时差** — 例如："Roko 先转头；0.4 秒后 Rein；再 0.4 秒 Jax"

**三人永远不会完美同步** — 总是错开 0.3-0.5 秒。

## 七、表演五柱（来自 ACTING SKILL.md）

每个场景中的每个角色分解为五个元素：

| 柱 | 定义 | 规则 |
|----|------|------|
| **目标 Objective** | 角色在此场景中此刻从特定人物那里想要什么 | 永远是针对搭档的动词。不是状态 |
| **障碍与赌注 Obstacle & Stakes** | 什么阻止他们得到它 | 赌注越高，场景越紧张 |
| **策略 Tactics** | 此刻追求目标的具体方法 | 策略失败时活人会**换策略**。死演技是整场一个策略 |
| **节拍 Beats** | 最小行动单位 | 节拍结束时必须有**可见的行为变化** |
| **潜台词 Subtext** | 角色真正想什么/要什么 vs 说了什么 | 潜台词不被表演——它自行泄露 |

## 八、眼睛生命（Eye Life）— 每个角色必须

死板眼神是 AI 表演的第一大特征：

- **微扫视和视线目标** — 注视持续移动：眼睛漂移、思考时闪开、扫描细节后回到目标。永不在单一点上冻结
- **真实眨眼率** — 与状态绑定：压力下快速连眨；控制时缓慢 calm 眨眼；解离时眨一下然后失焦
- **活的眼神光** — 眼睛必须读起来是湿润的、有光的、活的
- **受控静止 = 选择，不是死板** — 如果是近乎不眨眼的捕食者冷静，眨眼稀少但**缓慢且故意**
- **眼睛领先思想** — 眼睛比头部转动先到达目标。思想在言语之前可读于眼中
- **眼睛随节拍反应** — 眨眼率、注视稳定度、眼神光温度都随节拍变化

## 九、禁止的表演行为

| ❌ 禁止 | 原因 |
|--------|------|
| "就站在那里说话" | 总有微动作 |
| 卡通式做鬼脸/过度夸张 | 破坏写实 |
| "眼睛看向天花板"表示思考 | 命名一个具体的视线方向 |
| 默认流泪 | 仅当剧本明确要求 |
| 多角色完美同步 | 总是错开时间 |
| 笼统的"看起来很紧张"/"看起来很开心" | 总是分解为肌肉、呼吸、眼神 |
| "他是紧张的" | 写下颤抖的下唇、沉重的吞咽、口吸气 |
| 无触发条件的习惯动作 | 每个习惯动作必须有触发条件 |

## 十、反 AI 测试（Anti-AI Test）

在交付任何提示词之前，阅读表演部分并问自己：

> *这读起来像来自 AI 提示词模板？还是像一个看过演员排练的导演的笔记？*

如果读起来像模板，重写。微节拍应该感觉来自一个特定的表演，而不是一个检查清单。

**判断标准**：
- 模板化 = 笼统形容词、对称动作、完美同步
- 导演笔记 = 具体肌肉名、不对称反应、时差错开、有触发的习惯动作
