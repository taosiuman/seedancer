## 核心原则

### 排除规则必须写

不写排除规则，模型会转移所有东西（包括你不想转移的）。

**示例**：
```
✅ @图片1 作为角色参考，保留面部特征和体型，不要转移服装。
❌ @图片1 是角色参考。（没有排除规则，模型可能转移一切）
```

### 参考胜过文本

图像/视频/音频参考是密集条件，文本重新描述参考会造成冲突。只提示参考**不能携带的东西**。

**示例**：
```
✅ @图片1 作为角色参考，保留外观。描述：角色向前走，镜头缓慢推进。
❌ @图片1 是黑发女孩穿红裙，她向前走，镜头推进。（重新描述了图片已有内容）
```

## 多角色组合示例

复杂项目可同时使用多种角色：

```
@图片1 = 身份（角色外观，排除：服装）
@图片2 = 环境（场景布局，排除：时间/光照）
@视频1 = 动作（运动风格，排除：角色外观）
@视频2 = 镜头（运镜轨迹，排除：主体）
@音频1 = 音频（节奏/情绪，排除：视觉风格）
@图片3 = 风格（色调/质感，排除：主体/构图）
```

### Seedance 2.5 新增组合

```
@图片1 = 白模（空间结构/姿态/机位，排除：材质/纹理）
@图片2 = 身份（角色外观填充白模）
@图片3 = 风格（渲染风格/材质/光照）

@图片1 = 绿幕主体（角色外观，排除：原背景光影）
@图片2 = 环境（目标场景，排除：主体）

@图片1-20 = 身份/环境/道具（群像叙事，多主体同时保持稳定）🆕
@视频1-5 = 动作/镜头参考
@音频1-3 = 音乐/环境音/对白
```

## 角色冲突诊断

| 症状 | 问题 | 修复 |
|------|------|------|
| 角色外观被参考视频改变 | 动作参考出血到身份 | 添加排除："不要转移角色外观" |
| 场景风格随参考图漂移 | 环境参考出血到风格 | 添加排除："不要转移光照/色调" |
| 白模渲染保留了塑料感 | 未声明排除 | 添加："不要转移白模无纹理外观" |
| 绿幕主体光影不匹配 | 未触发光影重渲染 | 指定："根据新场景光源重渲染光影" |
