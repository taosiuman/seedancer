## 核心原则

**先算时长，再分组。禁止先写镜头再修补。**

台词容量预检是硬门，必须在分组之前完成。不过此门，不进入分镜写作。

---

## 最低时长公式

```
最低时长 = 可发声汉字 ÷ 语速 + 标点停顿 + 反应留白
```

### 语速四档

| 档位 | 字/秒 | 适用情境 |
|------|-------|----------|
| 慢速压抑 | 2.5-3.2 | 恐惧、迟疑、压抑、真相揭示、告别 |
| 冷静克制 | 3.0-3.8 | 低声、压低声线、从容威胁、冷硬问句 |
| 正常对白 | 3.3-4.2 | 普通交流、解释、平稳叙述 |
| 快速急促 | 4.3-5.2 | 争吵、催促、慌乱、短句追问 |

### 标点停顿

| 标点 | 停顿时长 |
|------|---------|
| 逗号 | 0.20-0.35 秒 |
| 句号/问号/感叹号 | 0.35-0.60 秒 |
| 省略号/破折号 | 额外 0.5-2 秒 |
| 告别句/真相揭示 | 额外 0.5-2 秒 |

### 反应留白

每组默认动作预留 **3 秒**，可因源剧本提高，不得低于实际动作链需要。

## 计算步骤

### 1. 提取口型台词

从剧本中提取全部角色台词，包括：
- 现场对白
- 角色 OS（内心独白）
- VO（画外音）
- 电话声
- 录音
- 设备播报

以上都属口型台词，保留说话人与音色要求。

### 2. 计算最低发声时长

按各句最低时长**累计**，不能分别拿整镜时长比。

示例：
```
台词："你为什么骗我？"（6字 + 问号停顿）
语速：冷静克制 3.0-3.8 字/秒
最低时长 = 6 ÷ 3.5 + 0.5 = 2.2 秒
```

### 3. 预留动作反应时间

- 默认动作预留 3 秒
- 如有复杂动作链（开门、走向、递交），按实际需要提高
- 倾听反应时间按台词停顿计算

### 4. 判断容量

```
口型台词最低时长 + 视觉读取最低时长 + 动作反应预留 ≤ 组时长上限
```

- ✅ 通过 → 进入分组
- ❌ 超载 → 立即拆段

## 视觉读取锚点

微信、短信、屏幕、监控文字、设备提示属视觉读取：

- 原文与标点必须出现在可见载体上
- 按阅读速度预留停留时间
- **不产生说话人、不产生口型、不产生音色**

剧本 `△` 事件中的此类文字不得误判为角色对白。

---

## 拆段规则

### 拆点优先级

1. 原文 `。！？；` 优先
2. 其次 `，`
3. 再次自然换气处

### 拆点必须同时满足

1. 当前口型或读取已完成
2. 说话人口型可收束
3. 人物重心稳定
4. 关键道具归属清楚

### 禁止拆点

- 台词中途
- 屏幕文字未读完
- 接触中途
- 门扇运动中途
- 坠落中途

---

## 硬门检查

### 禁止行为

- ❌ 先写镜头，再用加速语速修补
- ❌ 先写镜头，再用重叠时间码修补
- ❌ 先写镜头，再用隐藏切镜修补
- ❌ 先写镜头，再删除反应来修补
- ❌ 音色设定为冷静、低沉、克制时，为了通过时长改用快速语速

### 正确做法

- ✅ 超载时拆组
- ✅ 拆组后重新计算最低时长
- ✅ 确保每组口型 + 动作 + 反应 ≤ 组时长上限

---

## 特殊规则

### 同一镜头多句台词

按各句最低时长**累计**，不能分别拿整镜时长比。

### 音色与语速冲突

音色设定为冷静、低沉、克制时，不得为了通过时长改用快速语速——应改为拆组。

### 提供了剧本却解析不出任何台词

直接报错，不静默跳过。

## 示例

### 示例 1：正常对白

```
台词："今天天气不错，我们去公园散步吧。"（15字 + 逗号 + 句号）
语速：正常对白 3.3-4.2 字/秒，取 3.8
最低时长 = 15 ÷ 3.8 + 0.3（逗号）+ 0.5（句号）+ 3（动作预留）
         = 3.9 + 0.3 + 0.5 + 3 = 7.7 秒
```

✅ 15秒组可承载

### 示例 2：超载情况

```
台词："我知道你在想什么。但你不能这样做。这是规定，你必须遵守。
      如果你不听话，后果自负。"（42字 + 3句号 + 1逗号）
语速：冷静克制 3.0-3.8 字/秒，取 3.4
最低时长 = 42 ÷ 3.4 + 3×0.5 + 0.3 + 3
         = 12.4 + 1.5 + 0.3 + 3 = 17.2 秒
```

❌ 超过 15 秒 → 必须在句号处拆段

### 示例 3：视觉读取

```
屏幕文字："紧急通知：明天上午 9 点全体会议。"（14字 + 冒号 + 句号）
阅读速度：3-4 字/秒，取 3.5
最低时长 = 14 ÷ 3.5 + 0.3（冒号）+ 0.5（句号）+ 1（反应）
         = 4 + 0.3 + 0.5 + 1 = 5.8 秒
```

✅ 15秒组可承载，不产生口型

## 与分组的衔接

台词容量预检通过后，进入分组阶段（`grouping-density.md`）。

分组时需确保：
- 每组台词最低时长 ≤ 组时长上限
- 拆段在稳定状态处
- 承接等式成立
