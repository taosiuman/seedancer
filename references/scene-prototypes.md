# 场景原型路由系统（Scene Prototype Router）

> 来源：skill_cn.md（Seedance 2.0 导演技能）+ shotlist-builder reference
> 用途：根据场景类型自动匹配摄影机行为、空间逻辑和时间结构

---

## 一、原型总览

场景原型分三大类九种，每种原型决定了摄影机焦点、空间动态和节拍逻辑。

### 动作原型（Action Prototypes）

| 原型 | 摄影机焦点 | 空间动态 |
|------|-----------|----------|
| **追逐 Chase** | 距离收窄/拉开。被追者在前，追赶者居后 | 路径变窄/展开 |
| **对决 Duel** | 摄影机位于优势方下方；优势权必须交替 | 格斗者交换位置 |
| **冲击 Impact** | 蓄力慢 → 命中快 → 余波慢 | 接触点 = 中心 |

### 通用原型（General Prototypes）

| 原型 | 变化内容 | 摄影机标志 |
|------|----------|-----------|
| **旅程 Journey** | 空间位置。路途、飞行、河流、行走 | 跟拍、航拍、并行。风景掠过 |
| **氛围 Atmosphere** | 无变化 — 情绪即内容。雨打玻璃、空旷街道 | 最小运动。缓慢推进或静态停留。微变化承载全部戏剧性 |
| **揭示 Reveal** | 隐藏 → 可见。门开、雾散、摄影机绕角 | 横摇、摇臂升降、推镜头揭示。摄影机控制观众何时看到主体 |

### 对话原型（Dialogue Prototypes）

| 原型 | 权力动态 | 摄影机标志 |
|------|----------|-----------|
| **对峙 Confrontation** | 交替 — 双方推进。主导权随交锋更替 | 紧贴过肩镜头，权力转换时摄影机过轴 |
| **审讯 Interrogation** | 不对称 — 一方索取，一方抗拒 | 问话者低角度，沉默时推进 |
| **谈判 Negotiation** | 均衡 — 双方各有所求 | 对称构图，相同景别 |

## 二、决策树

### 动作原型决策树

```
1. 有人追/被追？ ──YES──→ 【追逐 Chase】
   │ NO
   ▼
2. 双方交替占优？ ──YES──→ 【对决 Duel】
   │ NO
   ▼
3. 单一致命接触瞬间？ ──YES──→ 【冲击 Impact】
   │ NO
   ▼
4. 默认 → 【对决 Duel】
```

**对决规则**：任一方连续占据优势不超过一个节拍。如一方全程主导，描述为单方面进攻而非交替优势的对决。

### 通用原型决策树

```
1. 主体在空间中移动/改变位置？ ──YES──→ 【旅程 Journey】
   │ NO
   ▼
2. 某物从隐藏变为可见？ ──YES──→ 【揭示 Reveal】
   │ NO
   ▼
3. 无变化 — 情绪即内容？ ──YES──→ 【氛围 Atmosphere】
   │ NO
   ▼
4. 默认 → 【氛围 Atmosphere】
```

### 对话原型决策树

```
1. 双方推进，主导权交替？ ──YES──→ 【对峙 Confrontation】
   │ NO
   ▼
2. 一方索取，一方抗拒？ ──YES──→ 【审讯 Interrogation】
   │ NO
   ▼
3. 双方各有所求，势均力敌？ ──YES──→ 【谈判 Negotiation】
   │ NO
   ▼
4. 默认 → 【对峙 Confrontation】
```

## 三、各原型详细规则

### 追逐 Chase

- **摄影机**：跟拍，距离变化是唯一节拍——收窄表示接近，拉开表示失去
- **空间**：路径先窄后宽（或先宽后窄），地形作为障碍
- **节拍**：距离变化 = 节拍变化。每次距离改变对应一次剪辑或镜头模式变化
- **物理**：跑步有真实重量感，脚触地、体重转移、对侧手臂摆动、躯干前倾

### 对决 Duel

- **摄影机**：位于当前优势方下方，优势转换时摄影机过轴
- **空间**：格斗者交换位置，形成空间权力地图
- **节拍**：每个回合 ≤ 1 节拍。优势交替是核心——如果一方全程压制，这不是对决
- **关键**：描写力量和方向，不描写破坏过程。✅ "driven into the car, metal buckling" ❌ "thrown into side door, glass shatters, uses rebound to sweep leg"

### 冲击 Impact

- **摄影机**：三段式节奏——蓄力用慢镜头/慢推，命中瞬间用闪切/硬切，余波用慢速拉远或静态
- **空间**：接触点 = 一切的中心
- **节拍**：蓄力（2-3 秒）→ 命中（0.3-0.5 秒）→ 余波（剩余时间）
- **物理**：命中瞬间有真实质量传递，身体反应有惯性

### 旅程 Journey

- **摄影机**：跟拍/航拍/并行。风景是内容
- **空间**：线性位移，有起点和终点
- **节拍**：空间变化 = 节拍。每段地形/光线变化对应一次剪辑
- **摄影机语言**：tracking、dolly、aerial、pan——摄影机随主体移动

### 氛围 Atmosphere

- **摄影机**：最小运动。静态停留或极缓慢推进
- **空间**：固定，无位移
- **节拍**：微变化承载全部戏剧性——光线变化、雨滴、风吹、烟雾流动
- **关键**：情绪即内容。没有事件发生——但画面必须活着

### 揭示 Reveal

- **摄影机**：横摇（pan）、摇臂升降（crane）、推镜头（push-in/dolly-in）
- **空间**：摄影机控制观众何时看到主体——主体先隐藏，后暴露
- **节拍**：隐藏 → 过渡 → 可见。三段式
- **关键**：门开、雾散、摄影机绕角——揭示机制必须在物理空间中可信

### 对峙 Confrontation

- **摄影机**：紧贴过肩镜头（OTS），权力转换时摄影机过轴（cross the line）
- **空间**：两人距离 = 权力图。距离缩短 = 升级，距离拉大 = 退让
- **节拍**：每次主导权翻转 = 一个节拍。2-4 个节拍/场景
- **台词限制**：约 25-30 个口语词可塞入 15 秒视频。保留权力转换的交锋句、前一句（铺垫）和后一句（反应），其余转化为肢体行为

### 审讯 Interrogation

- **摄影机**：问话者低角度（仰拍），沉默时缓慢推进
- **空间**：不对称——问话者占据更多画面空间
- **节拍**：提问 → 沉默/抗拒 → 突破。三段式
- **关键**：摄影机始终偏向问话者的权力位置

### 谈判 Negotiation

- **摄影机**：对称构图，相同景别，相同画面空间分配
- **空间**：平等距离，无明显的权力倾斜
- **节拍**：提案 → 反提案 → 共识/僵局
- **关键**：摄影机不偏袒任何一方

## 四、混合原型处理

当场景包含多种原型特征时：
1. 用决策树确定**主导原型**
2. 主导原型决定摄影机行为和空间逻辑
3. 次要原型作为**节拍变化**嵌入——例如对峙场景中的冲击时刻，或旅程中的揭示

## 五、对话字数与节拍转换

| 场景时长 | 最大对话词数 | 备注 |
|---------|------------|------|
| 5 秒 | ~10 词 | 一句短语 + 反应 |
| 10 秒 | ~20 词 | 一句铺垫 + 一句交锋 |
| 15 秒 | ~30 词 | 铺垫 + 交锋 + 反应 |
| 15+ 秒 | 仅用物理行为 | 超出部分全部转化为肢体 |

**原则**：多余的对话 = 丢失的肢体表演。每句未说出的台词都应该变成一次肌肉运动、一次呼吸变化、一次视线转移。
