# QA Checklists — 质检清单（门控 8 的落点）

> 本文件是**门控 8（质量检查）**使用的清单集合，也是 `failure-codes.md` 中
> “Part C 视觉图鉴”的宿主。此前它被 6 处引用却**不存在**（v8.0.0 的真实缺陷，见 `REV-20261005-007`），
> v9 重构补齐 —— 门控 8 的清单自此有家可归。

> 用法：出片前逐部分过；命中问题 → 用 `failure-codes.md` 的错误码命名 → 按责任层修复。

## Part B — 硬门清单（不可跳过）

- [ ] 台词容量预检：最低时长公式通过（**禁止用"加速语速"修补**）
- [ ] 分组硬门：时长上限（按模型）/ 拆组规则 / 组尾=可继承稳定状态 / 承接等式
- [ ] 镜头密度四道门：三档 + Smin/Bmin/Gmax 同时通过；**隐藏切镜 = 直接失败**
- [ ] 运镜设计：主动运镜三要素齐备；缓慢运镜 ≥3s；每镜 ≤2 个运动分量
- [ ] 输出格式：区块名**逐字使用**；每镜四项事实齐备；时间码规范
- [ ] 空间与人物指代硬门：无代词直指、无模糊方位（逐字词表见 `output-format.md`）
- [ ] 媒介翻译表已应用；体量控制在区间内
- [ ] CINEDANCE 16-block 架构完整
- [ ] Style Prefix 逐字粘贴
- [ ] GEO 空间锁定已写入
- [ ] 视频模型**已询问用户**（不得自行选定）

## Part C — 视觉图鉴（14 条 slop）

**判定标准以反空洞词典为准**：`anti-slop-lexicon.md`。本清单只做入口与命名映射；
错误码映射表见 `failure-codes.md` §4。

出图/出片后逐条对照，命中即用错误码命名：

- [ ] 死脸 / 表情丢失
- [ ] 视线漂移 / 无明确视线对象
- [ ] 肢体僵硬 / 关节不合理
- [ ] 手部畸变
- [ ] 服装与造型跳变（跨镜不连贯）
- [ ] 光源不一致（方向 / 色温跳变）
- [ ] 空间关系错乱（跳轴、越轴、方位矛盾）
- [ ] 尺度失效（人物与场景比例失真）
- [ ] 材质塑料感
- [ ] 背景空洞 / 无信息
- [ ] 运动模糊异常 / 拖影
- [ ] 面部身份漂移（同一角色不同脸）
- [ ] 文字 / 符号畸变
- [ ] 风格漂移（跨镜风格不统一）

> ⚠️ 上述 14 条为**检查项名称**；具体判定阈值与典型样例以 `anti-slop-lexicon.md` 为准。
> 若两处不一致：以词典为准，并回修本清单（一致性由 `scripts/check_consistency.py` 的 D1 项监测）。
