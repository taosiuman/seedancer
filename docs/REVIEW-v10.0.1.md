# Seedancer v10.0.1 评估报告

> 本报告随 PR 一起提交，记录对技能的整体评估与改进落地情况。第一轮提交只落地了**零风险、可自动验证**的部分（计算器 / SKILL.sh / 测试 / CI）；第二轮提交按第三节建议修改了 SKILL.md 与 `_meta.json` 正文。

## 一、总体评价

优点：

- **工程化程度高**：19 项一致性检查（版本、链接、索引、锚点、体积预算）+ 攻击测试，在提示词类技能里很少见。
- **硬门思路正确**：台词容量、分组时长、镜头密度都给出了可计算的公式，而不是"尽量"之类的软约束。
- **渐进加载**：主文件 + 48 份 references + 加载表，控制了上下文成本。

主要问题：

1. **公式靠模型心算**。Smin、台词最低时长、组时长上限都是确定性计算，但没有执行工具，模型最容易在这里算错且无法复核。→ 已新增计算器。
2. **SKILL.sh 是玩具**。时长/画幅写死为 10s/16:9，忽略用户输入，`--help` 不存在。→ 已重写。
3. **没有 CI**。检查脚本只能手动跑，规则再严格也会漂移。→ 已新增 workflow。
4. **公式常量只存在于文档**。改了表忘了改别处无人发现。→ 新增单元测试直接从 SKILL.md 读表比对。
