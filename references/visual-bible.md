# 视觉圣经模板 v1.0

> 借鉴 ShotFunClaw `picture-book-story-video` 的视觉圣经设计

---

## 核心概念

视觉圣经（Visual Bible）是影视制作中的标准文档，用于锁定整部作品的视觉风格、角色外观、场景氛围，确保所有生成内容保持一致性。

---

## 1. 视觉圣经结构

### 1.1 文档组成

```
视觉圣经/
├── 01-项目概述.md          # 项目基本信息
├── 02-视觉风格.md          # 整体视觉风格定义
├── 03-角色设计.md          # 角色外观规范
├── 04-场景设计.md          # 场景氛围规范
├── 05-色彩方案.md          # 色彩使用规范
├── 06-光影规则.md          # 光影使用规范
├── 07-镜头语言.md          # 镜头使用规范
└── 08-禁止元素.md          # 明确禁止的元素
```

### 1.2 核心字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `projectName` | string | ✅ | 项目名称 |
| `visualStyle` | string | ✅ | 视觉风格描述 |
| `colorPalette` | array | ✅ | 色彩方案 |
| `characterDesigns` | array | ✅ | 角色设计规范 |
| `sceneDesigns` | array | ✅ | 场景设计规范 |
| `forbiddenElements` | array | ✅ | 禁止元素列表 |

## 2. 视觉风格定义

### 2.1 风格要素

```markdown
## 视觉风格

### 整体基调
- 风格类型：写实/卡通/赛博朋克/古风/...
- 情绪基调：紧张/温馨/悬疑/欢快/...
- 时代背景：现代/古代/未来/...

### 视觉参考
- 参考作品：《XXX》《XXX》
- 参考导演：XXX、XXX
- 参考摄影师：XXX

### 技术规格
- 画幅比例：16:9 / 9:16 / 2.35:1
- 帧率：24fps / 30fps / 60fps
- 分辨率：1080p / 4K
```

### 2.2 色彩方案

```markdown
## 色彩方案

### 主色调
- 主色：#FF6B6B（珊瑚红）
- 辅色：#4ECDC4（青绿色）
- 强调色：#FFE66D（明黄色）

### 色彩比例
- 主色：60%
- 辅色：30%
- 强调色：10%

### 色彩情绪
- 主色：热情、活力
- 辅色：平静、专业
- 强调色：注意、重点
```

### 2.3 光影规则

```markdown
## 光影规则

### 光源类型
- 主光源：自然光/人工光
- 补光：柔和补光
- 背光：轮廓光

### 光影风格
- 对比度：高/中/低
- 阴影：硬阴影/软阴影
- 光比：3:1 / 5:1 / 10:1

### 禁止光影
- ❌ 过度曝光
- ❌ 完全不合理的阴影方向
- ❌ 闪烁的光源（除非剧情需要）
```

## 5. 镜头语言规范

### 5.1 镜头类型

```markdown
## 镜头类型使用规范

### 常用镜头
- 全景（Full Shot）：展示角色全身和环境
- 中景（Medium Shot）：展示角色腰部以上
- 近景（Close-up）：展示角色面部表情
- 特写（Extreme Close-up）：展示细节

### 镜头使用场景
- 全景：开场、转场、展示环境
- 中景：对话、日常动作
- 近景：情感表达、重要对话
- 特写：关键细节、情绪高潮

### 禁止镜头
- ❌ 过度使用鱼眼镜头
- ❌ 无意义的荷兰角
- ❌ 频繁切换镜头角度
```

### 5.2 镜头运动

```markdown
## 镜头运动规范

### 常用运动
- 推镜头（Push In）：强调重点
- 拉镜头（Pull Out）：展示环境
- 摇镜头（Pan）：展示横向空间
- 移镜头（Track）：跟随角色移动

### 运动速度
- 快速运动：紧张、急促
- 中速运动：正常叙事
- 慢速运动：抒情、沉思

### 禁止运动
- ❌ 无意义的快速旋转
- ❌ 过度使用手持晃动
- ❌ 突然的镜头跳跃
```

## 6. 禁止元素清单

### 6.1 视觉禁止

```markdown
## 禁止元素

### 明确禁止
- ❌ 暴力血腥场面
- ❌ 色情内容
- ❌ 政治敏感符号
- ❌ 品牌Logo（除非剧情需要）

### 风格禁止
- ❌ 卡通化表情（写实风格）
- ❌ 过度美颜
- ❌ 不合理的特效

### 技术禁止
- ❌ 模糊的画面
- ❌ 过度曝光
- ❌ 不合理的色彩
```

### 6.2 叙事禁止

```markdown
## 叙事禁止

### 逻辑禁止
- ❌ 角色瞬移
- ❌ 时间线混乱
- ❌ 道具凭空出现/消失

### 情感禁止
- ❌ 突然的情感转变
- ❌ 无铺垫的冲突
- ❌ 不合理的结局
```
