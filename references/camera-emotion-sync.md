# 摄影机-情绪同步系统（Camera–Emotion Sync）

> 来源：shotlist-builder reference/CAMERA_EMOTION.md
> 核心原则：**摄影机是焦点角色的情绪分身**。摄影机运动、镜头、时长必须由角色情绪状态决定——不是由"好看"决定。

---

## 一、情绪→摄影机类型映射表

| 焦点角色情绪 | 摄影机类型 | 中文描述 |
|-------------|-----------|----------|
| **愤怒/暴怒/紧张/紧绷** | 手持呼吸，**抖动、不稳定** — 破碎的呼吸节奏，可见的上下/左右微颤。小振幅、不规则节奏 | `摄影机不安、紧张——画面有较明显的呼吸式漂移、上下微抖、左右轻摆。手持摄影，画面带有不规则的呼吸节奏。禁稳定器。` |
| **平静/控制/自信** | 手持呼吸，**平稳** — 稳定的呼吸、规律的微振幅 | `摄影机平稳、流畅、克制——只剩下极细微的、规律的呼吸式微动。手持摄影但呼吸感极微。禁稳定器。` |
| **悲伤/脆弱** | 手持，**缓慢、低位** — 更低的呼吸频率，轻微下沉感 | `摄影机缓慢、低位手持——呼吸节奏放慢，画面有极轻微的下沉感。` |
| **震惊/揭示** | 静态 + 慢推/慢拉 — 开头严格静止，然后极慢运动 | `镜头开始严格静止——0.5秒后开始极缓慢推进/拉远，整段移动距离不超过15厘米。` |
| **动作** | 60fps，180°快门 — 清晰的运动，仅快门范围内的运动模糊 | `60fps流畅运动，180°快门运动模糊，禁止超出快门范围的拖影。` |
| **最终节拍/判决** | 0.3-0.5 秒正上方俯拍定格 — 时间静止 | `严格正上方俯拍（top-shot）。0.3-0.5秒freeze frame。所有人物位置冻结。时间静止。` |

## 二、情绪弧线（单镜头内情绪变化）

当情绪在一个连续镜头内**变化**时（如角色从愤怒 → 控制），摄影机**同步变化**。必须显式写出分阶段变化：

### 模板

```
⚠️镜头开始（步骤①②阶段，[角色][情绪A]）：摄影机⚠️明显手持、不安、紧张——画面有明显的呼吸式漂移、上下微抖、左右轻摆。

⚠️随[角色]情绪逐步缓和（步骤③④⑤）：摄影机的不安⚠️逐渐减弱——呼吸式漂移幅度变小，左右晃动减少，画面开始稳定。

⚠️镜头结尾（步骤⑥⑦，[角色][情绪B]）：摄影机⚠️变得平稳、流畅、克制——只剩下极细微的、规律的呼吸式微动。
```

**关键**：将每个摄影机阶段绑定到编号的表演节拍（① ② ③ ...），让模型知道在镜头的什么时间点进行转换。

## 三、镜头选择规则

### 焦距选择

| 用途 | 镜头 | 光圈 |
|------|------|------|
| 极致情感特写（额头到下巴填满画幅） | **85mm** 或 **100mm** | F1.4 |
| 中段对话、双人镜头 | **50mm** | F2.0 – F2.8 |
| 全景/建立镜头 | **35mm** | F4 – F5.6 |
| 道具/物件插入特写 | **50mm** 或 **85mm**，焦点锁定物件 | F1.4 |
| 微距（毛孔、水滴、织物） | **45mm macro** | F2.8 |

### 以可视结果描述镜头（Seedance 优先规则）

Seedance 对可视镜头结果响应更好，而非镜头元数据。优先使用：
- 对角线视场角（degrees）：47°（标准）、84°（经典广角）、107°（宽幅直线）、29°（短长焦）、18°（经典长焦）、8°（超长焦）
- 物理摄影机距离
- 可见的光学效果

**避免**以 mm 值、f 值、ISO、镜头品牌名作为主要控制手段。

### 镜头选择决策树

| 内容类型 | 镜头选择 |
|---------|---------|
| 脸部肖像 - 亲密 | 84° Cuarón 亲密广角 |
| 脸部肖像 - 中段 | 29° 短长焦肖像 |
| 脸部肖像 - 极致情感 | 18° 经典长焦 |
| 脸部肖像 - 远距离隐藏观察 | 8° 超长焦 + 前景遮挡 |
| 环境动作 - 自然 | 47° 标准 |
| 环境动作 - 宽幅 | 84° 经典广角 |
| 环境动作 - 大地理 | 107° 宽幅直线 |
| 细节/微距 | 29° 或 18°（独立节拍） |
| 远距离观察 | 8° 超长焦 + 前景遮挡 |

### 内容-视场角对齐规则

- 广角 → 环境、空间、物理、沉浸式、身体贴近摄影机
- 长焦 → 肖像、观察、隔离、压缩、远距离注视
- 微距/细节 → 独立插入节拍
- **不要**在同一节拍内混合不同内容类别（脸部肖像 + 大地理 + 微距 = 镜头漂移）

## 四、运镜时长规则

| 镜头类型 | 时长 |
|---------|------|
| 硬切闪入/闪现建立（瞬间全景） | **0.3 – 0.5 秒**（不是 1 秒！） |
| 一句台词，中等长度 | **3 – 7 秒** |
| 无台词反应（有情绪弧线） | **5 – 10 秒** |
| 插入/全景/定格 | **0.3 – 2 秒** |
| 情感特写（完整弧线，5-7 个编号节拍） | **8 – 15 秒** |

**完整提示词包络 = 15 秒**。多镜头提示词在此包络内分配。

---

## 五、Dolly / Track 运动规则

对于极慢 dolly（道具/设备特写），指定**精确距离和时间**：

```
整个7秒内摄影机后移总距离仅约10-15厘米。速度慢到几乎察觉不到。
```

**永远不写 `zoom`**。永远写物理摄影机运动：`dolly`、`track`、`crane`、`push-in`、`pull-out`。

---

## 六、禁用动作

| 禁止 | 原因 | 替代方案 |
|------|------|---------|
| `禁zoom变焦` | zoom 不是物理运动 | 用 dolly/track/push-in/pull-out |
| `禁稳定器` | 手持必须有可见呼吸感 | 手持呼吸 = 真实摄影师贴身跟拍 |
| `禁抖动`（除手持呼吸感） | 无意义的抖动不是情绪 | 抖动必须服务于情绪状态 |
| `禁过度运动` | 亲密剧本 = 亲密摄影机 | 如果情绪是内敛的，摄影机也内敛 |
| `禁桶形/枕形畸变` | 光学畸变破坏真实感 | 画面线条必须笔直 |
| `禁焦点漂移` | 焦点锁定是情绪锚点 | `焦平面严格锁定在 [目标] 上` |
| `禁rack focus` | 焦点转移 = 情绪转移，必须显式控制 | 如需转移，分镜处理 |

## 七、常用模板

### 7.1 极致大特写对话（85mm, F1.4）

```
机位：⚠️85mm（或100mm）长焦，⚠️F1.4极浅景深，⚠️[Character]⚠️严格的极致大特写——构图严格"额头到下巴填满画幅"。
⚠️摄影机⚠️严格手持，全程明显的呼吸式漂移和微动——真实摄影师贴身跟拍的呼吸感、心跳感。
⚠️摄影机⚠️主动跟随[Character]的脸部运动——头部任何细微的转动、抬起、下沉、目光移动，摄影机都微微跟随调整构图。
背景：⚠️完全虚化为模糊色块和柔光斑。
```

### 7.2 道具插入特写（焦点锁定）

```
机位：50mm/85mm 大光圈定焦，⚠️F1.4极浅景深，⚠️焦平面严格锁定在[object]上——绝对禁止焦点漂移。
⚠️只有[object]绝对清晰锐利，所有其他元素强烈散焦。
dolly out运动幅度极小：整个X秒内总位移仅约10-15厘米。禁zoom，禁突然推拉。
```

### 7.3 闪入建立镜头（瞬间）

```
机位：35mm广角，全景。⚠️持续时间⚠️严格约0.3-0.5秒（split-second flash——只是瞬间空间定位的闪现）。
0.3-0.5秒后⚠️立刻硬切到下一镜头——无过渡、无淡出、无停留。
```

### 7.4 正上方定格结尾

```
机位：严格正上方俯拍（top-shot）。0.3-0.5秒freeze frame。
所有人物位置冻结。时间静止。
```
