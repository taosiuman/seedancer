# 八项原片对照自检协议 v1.0

> 确保转绘/重绘内容与原片高度一致

---

## 八项自检内容

### 1. 台词保留检查
- [ ] 原片台词完整保留
- [ ] 台词时间点对齐
- [ ] 台词情感一致
- [ ] 无遗漏、无添加

### 2. 剧情覆盖检查
- [ ] 所有剧情点都有对应画面
- [ ] 剧情顺序一致
- [ ] 剧情节奏一致
- [ ] 无剧情遗漏

### 3. 角色出场检查
- [ ] 角色出场顺序一致
- [ ] 角色出场时间一致
- [ ] 角色动作一致
- [ ] 角色表情一致

### 4. 场景匹配检查
- [ ] 场景类型匹配
- [ ] 场景布局匹配
- [ ] 场景细节匹配
- [ ] 场景氛围匹配

### 5. 道具使用检查
- [ ] 道具出现时机一致
- [ ] 道具使用方式一致
- [ ] 道具位置一致
- [ ] 道具细节一致

### 6. 连续性检查
- [ ] 镜头间连续性
- [ ] 角色动作连续性
- [ ] 场景转换连续性
- [ ] 时间线连续性

### 7. 重复与连贯性检查
- [ ] 无重复画面
- [ ] 无重复动作
- [ ] 画面连贯
- [ ] 动作连贯

### 8. 运镜手法检查
- [ ] 镜头运动一致
- [ ] 镜头角度一致
- [ ] 镜头节奏一致
- [ ] 镜头情感一致

---

## 自检流程

```
1. 加载原片分析数据
2. 加载生成内容数据
3. 逐项对比检查
4. 生成自检报告
5. 标记不合格项
6. 提供修复建议
```
